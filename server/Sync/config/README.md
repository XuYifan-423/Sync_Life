# 配置文件说明

## 目录结构
- `n8n.py` - N8N工作流配置

## N8N配置 (`n8n.py`)

### 数据库配置
- `host`: 数据库服务器地址
- `port`: 数据库端口
- `database`: 数据库名称
- `user`: 数据库用户名（只读权限）
- `password`: 数据库密码

### Webhook配置
- `N8N_WEBHOOK_URL`: N8N工作流的webhook URL

## 使用方法
1. 确保数据库服务已启动
2. 确保已创建具有只读权限的数据库用户
3. 在N8N工作流中使用这些配置连接数据库
4. 定期检查配置文件，确保信息准确

## 安全注意事项
- 不要将密码等敏感信息提交到版本控制系统
- 定期更新数据库密码
- 限制数据库用户的权限，只授予必要的权限
